What this is

WreckerB runs on Nuxt 4 with no UI component library at all; every page is built from plain CSS and Vue primitives. It is a fully static, public site — no sign-up, no login, anyone can use the search shortcuts.

  • Zero third-party UI dependencies; styling and interaction are hand-written CSS and Vue
  • Only three top-level pages, flat navigation, everything is one click away
  • Chinese and English plus light/dark themes, adapted to mobile with media queries
